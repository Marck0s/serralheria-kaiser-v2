# Serralheria Kaiser — Site Profissional

## Stack
- Next.js 15 (App Router)
- Tailwind CSS 4
- TypeScript
- Lucide React

## Como rodar localmente
```bash
npm install
npm run dev
```

## Como fazer deploy
```bash
npm run build
```

Pode ser deployado na **Vercel** em 1 clique conectando o repositório.

## Estrutura
- `app/` — Layout, globals, página principal
- `components/` — Seções: Navbar, Hero, Services, About, Stats, Partners, Testimonials, CTA, Contact, Footer, WhatsApp
